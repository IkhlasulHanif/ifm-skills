# IFM Skills

Agent skills for building with the [IFM](https://docs.ifm.ai) hosted API — K2 Horizon, K2 V2, Jais 2, and Jais-ASR.

## Install

```bash
npx skills add IkhlasulHanif/ifm-skills
```

Works with Claude Code, Cursor, Codex, and other agents supported by [skills.sh](https://skills.sh).

## Skills

| Skill | Description |
| --- | --- |
| [`ifm-api`](skills/ifm-api/SKILL.md) | OpenAI-compatible chat completions, reasoning effort & trace replay, tool calling, streaming, structured output, session routing, audio transcription, limits/errors, and K2 V2 → K2 Horizon migration. |
